# Rwanda Connect 🇷🇼

**Rwanda Connect** is a modern directory prototype designed to help people discover useful places, services, businesses, transport options, healthcare, hotels, restaurants, and opportunities across Rwanda.

## ✨ What makes Rwanda Connect stand out

- 🔎 Fast keyword search and category filtering
- 📍 City-based discovery
- 🌐 Visible **English / Kinyarwanda language switcher**
- 📱 Responsive design for phones, tablets, and desktops
- 🧭 Clean discovery-focused interface
- 🪪 Clear demo-listing labels to avoid presenting sample data as official information
- ⚡ No build step: the prototype runs directly from `index.html`
- ♿ Accessible controls, readable contrast, and keyboard-friendly interaction
- 📞 Direct support contact links

## ▶️ Run locally

Simply open `index.html` in a modern web browser. No build step or server is required for the current prototype.

## 🌍 Languages

The website includes a visible language selector in the navigation. Users can switch between:

- **English**
- **Kinyarwanda**

The selected language is remembered in the browser using `localStorage`.

## 🚀 Future growth

The current project is a frontend prototype. A production version could add verified business accounts, a real database, maps, user accounts, reviews, favorites, advanced search, real-time listings, moderation, notifications, analytics, and an administration dashboard.

> **Important:** Sample listings in the prototype are for demonstration and discovery. They should be verified before being treated as official contact or service information.
